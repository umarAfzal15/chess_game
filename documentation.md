## This Chess Game
Built using C++ for logic and raylib (library) for GUI interface.

## Naming Convention

The names for piece files are followed by either 1 or 2, then a number indicating the power or importance of the piece.

For example:

The number 11 — the first 1 means it's a Black piece, the second 1 means it's a pawn, the least powerful piece.

Similarly, the number 23 — 2 means it is a white piece, 3 means it is a Bishop, the 3rd most powerful piece on the chessboard.
